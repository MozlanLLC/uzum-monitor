# Uzum Монитор цен

Android-приложение: следит за ценой, наличием и количеством товаров на uzum.uz,
проверяет каждые полчаса (в :00 и :30) и присылает уведомление при изменениях.

**Скачать APK:** https://github.com/MozlanLLC/uzum-monitor/releases/latest/download/uzum-monitor.apk

- `android/` — оболочка приложения. При изменениях GitHub Actions собирает новый APK и публикует его в Releases.
- `web/` — обновляемая часть: интерфейс (`ui.html`) и логика чтения карточки товара (`extract.js`).
  Приложение само скачивает её, когда в `manifest.json` увеличивается `version`, — переустанавливать APK не нужно.

## Для разработки

- Изменения попадают в `main` только через pull request. На каждый pull request запускается проверочная сборка без подписи (`.github/workflows/check.yml`).
- После слияния `.github/workflows/build.yml` собирает подписанный APK и публикует релиз. Ключ подписи хранится в секретах `KEYSTORE_BASE64` и `KEYSTORE_PASSWORD`.
- Если новая функция интерфейса требует нового кода в `android/`, увеличьте `NEED_APP` в `web/ui.html` до номера сборки, в которой этот код появился. Приложения старше покажут сообщение «Вышла новая версия».
- Резервная копия (Настройки → Резервная копия) — это JSON-файл со списком товаров и историей проверок.
