# Uzum Монитор цен

Android-приложение: следит за ценой, наличием и количеством товаров на uzum.uz,
проверяет каждые полчаса (в :00 и :30) и присылает уведомление при изменениях.

**Скачать APK:** https://github.com/MozlanLLC/uzum-monitor/releases/latest/download/uzum-monitor.apk

**Расширение для браузера (Chrome, Edge, Яндекс Браузер, Opera и другие на базе Chromium):**
https://github.com/MozlanLLC/uzum-monitor/releases/latest/download/uzum-monitor-extension.zip — как установить, см. ниже.

- `extension/` — расширение для браузера: тот же интерфейс и та же логика чтения карточки, что в приложении.
- `android/` — оболочка приложения. При изменениях GitHub Actions собирает новый APK и публикует его в Releases.
- `web/` — обновляемая часть: интерфейс (`ui.html`) и логика чтения карточки товара (`extract.js`).
  Приложение само скачивает её, когда в `manifest.json` увеличивается `version`, — переустанавливать APK не нужно.

## Расширение для браузера

Проверяет цены каждые полчаса, пока открыт браузер, и показывает уведомления. Цены видит так же, как вы на сайте:
если вы вошли на uzum.uz, они будут личными. Для проверки ненадолго открывает страницы товаров в свёрнутом окне.

Установка:

1. Скачайте `uzum-monitor-extension.zip` и распакуйте в папку, которую не будете удалять.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Яндекс Браузере — `browser://extensions`).
3. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение», выберите распакованную папку.
4. Закрепите значок расширения на панели браузера.

Обновление: распакуйте новый архив поверх старой папки и нажмите на странице расширений кнопку обновления у «Uzum Монитор цен».
Список товаров при этом сохраняется. При удалении расширения он стирается — заранее сохраните резервную копию в настройках.
Файл резервной копии общий с приложением для Android.

Уведомления: в настройках расширения есть кнопка «Проверить уведомление». Число на значке показывает новые изменения,
даже если система прячет уведомления.

В магазинах расширений оно не публикуется: ставится только из архива.

Сборка вручную: `node extension/build.mjs` — готовое расширение появится в `extension/dist`. Проверка логики: `node extension/test.mjs`.

## Для разработки

- Изменения попадают в `main` только через pull request. На каждый pull request запускается проверочная сборка без подписи (`.github/workflows/check.yml`).
- После слияния `.github/workflows/build.yml` собирает подписанный APK и публикует релиз. Ключ подписи хранится в секретах `KEYSTORE_BASE64` и `KEYSTORE_PASSWORD`.
- Если новая функция интерфейса требует нового кода в `android/`, увеличьте `NEED_APP` в `web/ui.html` до номера сборки, в которой этот код появился. Приложения старше покажут сообщение «Вышла новая версия».
- Резервная копия (Настройки → Резервная копия) — это JSON-файл со списком товаров и историей проверок.
